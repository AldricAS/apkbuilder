Zip atau link web masuk, APK keluar.

Kirim proyekmu sebagai zip, atau tempel link situs yang sudah online. Kami rakit jadi APK debug di GitHub, lalu kamu tinggal unduh dan instal.

Batas 1 build per hari untuk setiap pengguna.

Jalur build

Statusnya diperbarui otomatis, halaman boleh dibiarkan terbuka.

  1. Mengirim zipFile dikirim ke repo GitHub
  2. MengantreMenunggu runner GitHub bebas
  3. Merakit APKGradle bekerja, biasanya 3 sampai 8 menit
  4. APK siapTombol unduh muncul di bawah
